# Feature Branch: Lost and Found Application

## Description
This feature branch contains the Flask application for the USIU Lost and Found System. It implements the main backend logic, including user authentication, item reporting, claim processing, and security officer workflows.

## Features Implemented
- User registration and login
- Lost item reporting
- Found item reporting
- Item claim submission
- Security officer verification
- Session management
- Image upload for found items

## Files
- usiulostnfound_app.py - Main Flask application.
- usiulostnfound_database.py - Database setup and connection.
- LostandFound_Usecase.png - Use case diagram.
